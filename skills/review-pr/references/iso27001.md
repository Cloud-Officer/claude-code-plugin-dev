## ISO/IEC 27001 — what to look for in a code change

- Data sent out: new exports, webhooks, emails, file shares or APIs that send data without encryption, authorization or a real need.
- Access: a new or changed endpoint, query, job or UI action that skips authorization, exposes another user's or tenant's records, or opens an admin path.
- Authentication: weak password or token storage, predictable tokens, sessions that never expire or survive logout, login or reset without rate limiting.
- Source and pipeline access: weakened CODEOWNERS, branch protection, CI permissions or deploy keys.
- Suppliers: personal or customer data sent to a new third-party API, SDK or SaaS.
- Records: audit or business records that can now be edited, deleted or lost.
- Personal data: new personal data collected without need, sent somewhere new, or kept without a retention path.
- Capacity: unbounded queries, loops, queues or uploads that can take the service down.
- File uploads: missing type, size or content checks, or storage reachable from the web.
- Dependencies: a new or bumped dependency that is unpinned, has a known serious vulnerability or is abandoned.
- Configuration: insecure defaults, debug modes, permissive CORS, disabled security headers.
- Deletion: deletion or retention code that leaves the data behind in backups, caches or search indexes.
- Data leakage: secrets or personal data in API responses, exports, error messages, analytics or URLs.
- Migrations and backups: destructive migrations with no way back, weakened backup settings.
- Logging and monitoring: security events no longer logged or alerted, secrets or personal data in logs.
- Network: new public exposure or weakened firewall rules and segmentation.
- Cryptography: weak algorithms, disabled TLS certificate verification, hardcoded keys or secrets.
- Secure coding: injection, unsafe deserialization, CSRF, SSRF, path traversal, missing input validation, missing output encoding.
- Environments and test data: production credentials, hosts or data in development, test or CI configuration; real customer data in fixtures.
